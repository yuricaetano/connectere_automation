# 🌟 Projeto de Automação de Testes com Playwright

Este projeto utiliza o **Playwright** com **JavaScript** e **Yarn** (ou **Node.js**) para automatizar testes. O objetivo principal é automatizar a inclusão de produtos por meio de uma planilha do Excel.

## 🚀 Tecnologias Utilizadas

- **Node.js**: Ambiente de execução do JavaScript
- **Yarn** ou **Node**: Gerenciador de pacotes
- **Playwright**: Para testes automatizados de aplicações web
- **Excel**: Para manipulação e inclusão de dados de produtos

## 📦 Instalação

Siga os passos abaixo para instalar as dependências e configurar o projeto:

1. Clone este repositório:
   ```bash
   git clone <URL-do-repositório>
   cd nome-do-repositorio
2. Instale as dependências usando o Yarn ou Node:
yarn install
npm install

3.Para executar os testes com Playwright:
yarn playwright test ou npm playwright test

💻 Uso
Para automatizar a inclusão de produtos, execute o seguinte comando:
# Inicia a execução do script de inclusão de produtos
yarn start ou npm start
.

## 🧪 Testes
Para rodar os testes automatizados, utilize o seguinte comando:
# Executa todos os testes
yarn test ou npm test

Os testes verificarão a inclusão de produtos em conformidade com os dados fornecidos na planilha.
